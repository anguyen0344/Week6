\# CS110 Week 6 — Action 6B

\## Civic Archive Dome — Original Story Signal



\### User and Purpose

This app is for a player entering my Civic Archive Dome story.

It asks for the character's name and displays a welcome message.



\### Tools

\- C#

\- WPF (.NET Framework)

\- Visual Studio



\### How to Run

1\. Open the ActionRecord6B solution in Visual Studio.

2\. Click Start.

3\. Enter a character name.

4\. Click "Enter the Dome."



\### Input → Variable → Output

The player types a name into CharacterNameBox.

When the button is clicked, the app stores the name in the

string variable characterName and displays a welcome message.



Example:

An → characterName = "An" →

"Welcome, An! The Civic Archive Dome awaits you."
